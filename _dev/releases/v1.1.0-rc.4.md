# Q-Solver v1.1.0-rc.4

这是 `lizhouya/Q-solver` 个人 fork 的预发布版本，不是上游官方发行版，也不是稳定版。项目继续遵循 CC BY-NC 4.0，仅限非商业个人学习与研究。

## 本次重点

### 解题工作流

- 截图恢复为最多三张，修复偶发快捷键阻塞，并在桌面和同步端显示真实截图数量与操作提示。
- 新增原图重试：视觉或网络请求失败时可复用本轮截图和上下文，不必重新截图。
- 新增中断当前解题，以及独立的快速解题模式；默认解题与快速解题共用同一安全任务管线。
- 修复 F10 快速解题、F12 删除截图及历史快捷键字段错配；桌面和同步端按 F8～F12 工作流顺序显示截图、发送、快速解题、中断和删除。
- 选择题改为先识别“原始选项字母 → 完整文本”映射，再判断正确文本并回填字母；正文、解析结论和最终汇总冲突时输出“待核对”。

### 模型与连接

- 增强 OpenAI-compatible、Anthropic-compatible、Responses 与 CCR 网关的协议识别、连接诊断和安全错误提示。
- 统一 API 连接 Profile，保存请求地址与密钥输入，支持刷新模型和测试连接；不再要求每次重新输入。
- 视觉失败会显示可操作错误，而不是把空白或不可见图片响应误当成正常答案。
- 模型下拉列表展开时锁定设置页外层滚动，避免滚轮意外移动主页面。

### 题库与同步端

- 改进题库整理失败恢复、逐题解析和历史分段保护；当前分段清空可执行物理删除，且不误删其他分段。
- 同步端优化答案可视空间、自动跟随和手动滚动，解题后不再遮挡底部内容。
- 本地清理后同步端同步清空；截图状态、五项快捷键提示和满三张状态保持一致。
- Mobile 仍是只读输出端，没有新增远程控制端点。

### 构建与维护

- 建立 `build/bin/**` 构建产物盘点、候选验证、哈希晋升、归档和回滚规则。
- 发布工具链继续固定 Wails v2.11.0，并通过 Tag 工作流生成 Windows amd64、macOS arm64、macOS amd64 和 `SHA256SUMS`。
- 本次没有新增依赖，也没有改变网络暴露边界。

## 下载与升级

- Windows x64：`q-solver-windows-amd64.exe`。首次运行可能出现未签名程序提示，请只从本仓库 Release 下载并核对 `SHA256SUMS`。
- Apple Silicon：`q-solver-macos-arm64.zip`；Intel Mac：`q-solver-macos-amd64.zip`。macOS 附件由 CI 构建，未签名、未公证，也没有人工桌面验收。
- 升级前备份自己的配置和题库输出，正常退出旧程序（包括托盘实例）。程序使用单实例锁，不要只隐藏旧窗口。
- 新版本继续读取原用户配置；不要把 API Key、Token 或 Mobile 连接 URL 复制到源码、公开文档或发布目录。
- 默认解题工作流提示为 F8 截图、F9 发送、F10 快速解题、F11 中断、F12 删除；如果在设置中重绑定，同步端会显示实际键名。

## 已验证与已知限制

- 最近本地 Windows 验证包括全量 Go 测试、`go vet`、`go build`、`go mod verify`、19 个前端 Node 回归和 Vite build；Change 032～041 的相关 GUI、跨电脑同步、快捷键、快速解题和实际模型选择题复验已有用户确认。
- 本 Tag 的实际三平台构建与回归结果以对应 GitHub Actions run 为准；自动构建不能代替人工验收。
- Windows race 测试进程启动仍返回 `exit status 0xc0000139`，状态为 `BLOCKED`；不宣称 race 通过。
- macOS 附件未经人工 GUI 验证，部分较早 Change 的真实 Provider、题库导出/整理矩阵仍保留 `NEEDS_USER`；因此本次只发布 RC，不标记稳定版或 Latest，也不代表所有历史 Change 已关闭。
- 连接测试、真实解题和显式启用的题库模型整理可能调用服务商并产生费用。
- 提示词约束只能降低选择题字母与文本错配概率，不能保证模型绝对正确。答案与整理稿均为参考内容，重要结论请自行核对。
- Vite 主 chunk 仍有大于 500 kB 的既有警告；本次未拆包。

## 安全与来源

- 本 Release 不包含用户配置、API Key、Token、题库内容、Mobile 连接 URL 或个人路径。
- 远端同步地址可能包含临时凭据，不要公开分享。
- 请使用本 Release 附带的 `SHA256SUMS` 验证下载文件；不要将个人 fork 与上游官方 Release 混用。
