## 背景与问题

电脑浏览器打开手机同步端时，答题端快捷键卡片长期占据较多纵向空间，压缩了答案可视区域。新答案或流式内容到达后，页面不会自动定位到最新结果，用户需要手动滚到底部。答题电脑发出的同步端滚动控制每次移动视口高度的 70%，单次幅度过大。

## 已批准行为

用户已批准以下 bounded 设计：

- 快捷键区域改为默认折叠的紧凑栏，展开后显示说明和快捷键网格；
- 跟随最新结果时，流式答案与最终答案更新后自动滚动到页面底部；
- 浏览历史答案时不强制自动滚动；
- 键盘控制单次滚动距离从视口高度的 70% 降为 40%；
- 不使用浏览器存储保存折叠状态。

## 验收标准

- [ ] 快捷键提示有数据时默认折叠，只保留紧凑摘要行。
- [ ] 用户可展开并查看完整说明与快捷键列表。
- [ ] 跟随最新答案时，`streaming` 和 `done` 渲染后会滚动到页面底部。
- [ ] 手动查看历史答案及后台新答案到达时不触发自动跟随。
- [ ] 远程键盘滚动幅度为视口高度的 40%，保持平滑滚动及控制序号去重。
- [ ] Mobile DOM、Go 全量测试与构建、Frontend build 通过；必要 GUI 验收如实记录。
