# Change 034：题库当前分段物理清空

## 背景

用户有时使用测试题，不希望测试分段长期保存在本地。现有“清空本段”只把分段标记为 `discarded`，`session.json` 和截图 assets 仍完整保留，与用户对“清空”的预期不一致。同时“结束本段”目前只封存，不会清理解题主界面的实时答案历史。

## 已批准行为

用户明确选择“清空即物理删除”：

- 解题过程仍按现有方式先落盘；
- 点击“清空本段”并二次确认后，永久删除当前分段记录、答案和截图文件；
- 清空成功后从历史列表移除，下一次解题懒创建新分段；
- 删除当前分段后清理桌面实时答案历史和该分段对应的模型上下文；
- 已经导出到其他目录的文件不删除；
- “结束本段”保留本地记录，但清理桌面实时答案历史；
- 导出继续执行现有整理、导出和自动封段流程。

## 验收标准

- [x] 清空前显示“永久删除、无法恢复”的明确二次确认。
- [x] 清空成功后当前分段目录、`session.json` 和 assets 不存在，历史列表不再包含该分段。
- [x] 清空成功后桌面实时答案和该分段模型上下文清除，下一题建立新分段。
- [x] 运行中、整理/导出中、未落盘或删除失败时拒绝，且不清理运行时状态、不显示成功。
- [x] 已导出文件不受影响；旧版本已软清空历史不追溯删除。
- [x] 结束本段成功后本地分段仍可查看/继续/导出，但桌面实时答案历史清空。
- [x] 导出行为与现有契约保持一致。
- [x] 聚焦、全量 Go、前端回归和构建验证通过；必要 GUI 验收如实记录。
