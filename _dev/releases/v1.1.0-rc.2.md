# Q-Solver v1.1.0-rc.2

这是 lizhouya/Q-solver 个人 fork 的首个预发布版本，不是上游官方发行版，也不是稳定版。遵循原项目 CC BY-NC 4.0，仅限非商业个人学习与研究。

## RC2 修正

- 修正题库一次性导出目录测试在 macOS `/var` 与 `/private/var`、Windows 8.3 与长路径之间的等价路径判断。业务导出目录行为不变。
- Mobile SSE 测试改用内核分配端口并读取实际端口，消除“探测后释放再重绑”的端口竞争。生产默认端口仍为 `38511`。
- `v1.1.0-rc.1` 的三平台应用构建成功，但回归步骤失败，因此未创建 Release；RC2 不移动或覆写 RC1 Tag。

## 更新内容

- 题库自动记录每次提交的截图与完整答案，按分段封存；软清空不删除恢复数据，重复导出创建新目录，不覆盖旧题库。
- 导出前确认名称、单位、题型、目录及本次模型整理授权。原始记录保留图片，整理稿为无图试卷及参考答案；关闭模型整理只导出原稿与图片。
- 主设置区分长期默认目录与单次导出选项，顶部明确显示提交次数，而非题目数量。
- 恢复 API 配置加载；模型查询与连接测试使用本次填写的地址和密钥。题库偏好失败不再阻断普通设置保存，配置未成功读取时阻止保存默认空值。
- 改进局域网同步连接状态与重试，远端可在手机或另一台电脑的浏览器打开。
- 修正实时答案序号及满队列终态丢失，远端不再需要逐题刷新；新增真实 Bridge → HTTP/SSE → 页面脚本回归。
- 顶部箭头、已保存键盘快捷键及箭头组内滚轮按输出模式控制滚动，控制帧不重建历史答案；不可用时回退桌面。
- 修复 Windows hook 的静态检查告警，发布工具链固定 Wails v2.11.0。

## 下载与升级

- Windows x64：q-solver-windows-amd64.exe。首次运行可能出现未签名程序提示，请仅从本仓库 Release 下载并核对 SHA256SUMS。
- Apple Silicon：q-solver-macos-arm64.zip；Intel Mac：q-solver-macos-amd64.zip。macOS 附件由 CI 构建，未签名、未公证，未进行人工桌面验收。
- 升级前备份自己的配置和题库输出，正常退出旧程序（含托盘），不要仅隐藏窗口。程序使用单实例锁。
- 新程序继续读取原用户配置，不需要把密钥复制进源码或发布目录。
- 远端同步请保存 dual 模式，并在应用重启后复制新连接地址。连接地址含临时凭据，不要公开分享。
- 键盘默认 Alt+PgUp/PgDn；滚轮仅在顶部箭头组内接管。dual 会同时控制本机和远端。

## 已验证与已知限制

- 本地 Windows：Go 全量测试、go vet、Go/Vite/Wails 构建、设置回归与 Mobile DOM/真实 SSE 联合测试通过。用户确认 API 解题、跨电脑实时显示及远程滚动可用。
- 本机 race 测试进程启动仍报 0xc0000139，状态为 BLOCKED；不宣称 race 通过。
- 题库导出弹窗/目录选择器完整人工验收、真实模型整理、部分重连/端口恢复矩阵仍未完成；macOS GUI 也未经人工验收。故本次仅发布 RC。
- 模型整理默认关闭；显式启用并确认导出后才上传该段截图与原答案，可能产生费用。连接测试也可能产生服务商费用。
- 答案与整理稿都是参考内容，不是官方答案；重要结论请自行核对。
- Vite 主 chunk 仍有大于 500 kB 警告；本次未拆包或新增依赖。

各平台 CI 的实际结果请查看本 Tag 对应的 Actions；自动构建不代替人工验收。此 RC 不代表 Change 010～014 全部关闭。
