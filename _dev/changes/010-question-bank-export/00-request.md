## 验收与边界


### 自动化测试（先用 fake provider，不调用用户真实模型）

- 多场次隔离、开始/结束边界、记录顺序、重复结束/导出。
- 一次 1～3 张截图全部保存，PNG/JPEG 格式正确；超过 10 轮、KeepContext 开/关、前端删除历史均不影响归档。
- desktop/mobile/dual 下记录一致，且不改变现有事件路由。
- 完整答案优先于分片；失败、取消、空答案、取消后迟到回调、处理中关闭场次不串题。
- 重启识别未结束场次，损坏记录可诊断，写入失败有反馈；临时目录或 JSON 文件损坏不得被标为成功。
- 中文与 Windows 非法文件名、目录穿越、同名导出、不存在/不可写输出目录、跨文件夹搬移后的相对图片链接。
- 整理 mock 覆盖成功、多题拆分、无效 JSON、缺失字段、错误来源映射、超时/取消、部分失败、只重试失败记录；原始截图和答案在所有分支保持不变。
- 归档与整理 payload 不携带密钥、简历、系统配置或 KeepContext 历史。
