## 这是什么

Q-Solver 是一个桌面端 AI 做题助手。

当前仓库是 [lizhouya/Q-solver](https://github.com/lizhouya/Q-solver) 个人 fork，基于 [jym66/Q-solver](https://github.com/jym66/Q-solver) 二次开发；下述题库归档是本 fork 的扩展，不代表上游发行版已包含。许可仍为 CC BY-NC 4.0，仅限非商业个人学习与研究。

你看到题目、代码报错、公式、图表或者英文内容时，不需要再切网页复制粘贴，直接截图就能把内容发送给模型分析。

它的核心特点是：

- 截图即问，适合算法题、笔试题、面试题和代码问题
- 支持隐藏模式，更适合低存在感使用
- 悬浮展示，不抢当前应用焦点
- 支持鼠标穿透，方便挂在屏幕边上随看随用
- 对多数录屏 / 共享场景更不显眼

## 核心功能

- AI 答题助手：截取桌面内容并直接发送给模型分析
- 原图重试与中断：网络失败可复用本轮 1～3 张截图重试，限时场景可真实中断当前请求
- 快速解题：请求级切换到 `gen-speed` 场景，不改写持久默认场景
- 历史记录：保留最近结果，方便连续查看
- 模型切换：手动刷新当前接口的候选模型目录，也可直接填写模型名称
- 场景预设：针对不同题型切换不同提示词风格
- 通用 API 接入：支持 OpenAI Chat 流式兼容服务和安全 JSON 非流式请求模板；旧 Responses/Anthropic 配置可生成迁移草稿
- 截图调节：压缩、锐化、灰度、原图上传可配置
- 简历解析：导入 PDF 简历并调用你自己的模型整理为 Markdown
- 桌面浮窗：支持隐藏模式、鼠标穿透、快捷键操作
- 低打扰体验：尽量不抢焦点，适合挂在桌面边缘随时查看

## 笔试题库归档（个人 fork）

题库记录独立于前端历史、`KeepContext` 和桌面/手机输出模式。日常做题不需要手动开始场次：

1. 在主“设置 → 题库”中选择 **Git 仓库外的默认题库目录**。设置页只保存默认目录和“默认启用模型整理”开关，不长期保存单位、出题方、题型或题库名称。
2. 完成第一道题时会懒创建“当前段”。后续解题继续追加到当前段；顶部的“本段 N 次提交”表示提交次数，一次提交可能含多道题。
3. 点击答案旁“导出题库”只会先打开确认窗口。可为本次填写招聘单位、出题方、题型、题库名称、临时导出位置，并决定本次是否调用模型；打开或取消窗口不会封存分段、上传内容或产生模型费用。
4. 默认名称按“招聘单位_出题方_题型”生成，自动忽略空值和重复项；单位与出题方都不明确时使用稳定编号，例如 `笔试_20261020_01_综合笔试`。手动修改名称后字段变化不再覆盖它，只有点击“恢复自动命名”才重新联动。
5. 关闭本次模型整理时，只在本地生成 `原始记录.md` 和 `assets/`。开启后先点击“整理并生成建议”，按尚未整理的提交逐条调用当前支持图片的模型，同时生成题目和元数据候选；候选始终标记为“待核对”，不会自动成为权威字段。全部失败时不能生成零题整理稿，可只重试失败记录或改为仅原稿；部分失败时可重试失败记录、明确导出已有结果或改为仅原稿。人工核对后再确认导出，最终导出是纯本地操作，不会再次调用模型。该流程不发送简历、完整配置、聊天历史或做题角色，也不覆盖原答案。
6. “结束本段”只封存当前段；下一道题自动进入新段。导出成功也会自动封段。“清空本段”是软清空：桌面实时历史回到干净待记录状态，但题库原始记录、截图、旧导出和模型上下文都继续保留，该段不再参与整理或导出。
7. 题库面板最多显示最近 20 个分段。点击行仍是独立只读查看；对 `ended`、`exported`、`paused` 分段点击“继续此分段”才会真正切换后台 current，并在截图解题主界面恢复该段全部提交、1～3 张截图和完整答案。原活动段会安全暂停，可稍后切回；`discarded` 永久只读。第 21 段及更早记录仅从界面隐藏，仍完整保留在文件系统，不会自动整理、导出或删除。续接已导出分段不会改动旧导出，再次导出使用 `_02`、`_03` 等后缀。
8. 完成一套题后，可点击答案操作栏的“开始下一套”或按 `Ctrl + Shift + N`。确认后，程序会安全封存当前段，并清空待发送截图、桌面历史和模型对话上下文；题库原始记录、归档截图、旧导出和同步端当前显示继续保留。导出、整理、解题或落盘仍在进行时会拒绝切换；下一次正式解题才懒创建新分段。

推荐工作区布局如下，实际迁移状态见 [Change 011](_dev/changes/011-job-workspace-layout/06-notes.md)：

```text
求职_AI/
├─ 求职笔试/                              # 多种笔试工具的分类目录
│  └─ Q-Solver/                           # 当前工具的完整源码、.git 与开发记录
├─ 求职网申/                              # 预留目录，本次没有网申程序
└─ 输出/
   ├─ 求职笔试/
   │  └─ 题库/                            # 设置中的默认 ArchiveDir
   │     ├─ _记录/<分段ID>/               # 恢复与重新导出的持久原始记录
   │     │  ├─ session.json
   │     │  └─ assets/
   │     └─ <日期_时间_题库名称>[_02]/
   │        ├─ <题库名称>.md               # 无图片试卷：前半试题，后半参考答案与解析
   │        ├─ 原始记录.md                 # 全部截图引用和完整原答案
   │        └─ assets/
   └─ 求职网申/
```

**边界与恢复：**

- 目录配置完成后，第一道题会自动开始记录；此前未录制或已丢失的历史无法事后补全。归档不受模型最近 10 轮上下文限制。
- 一次提交可能包含多题；原稿按提交顺序完整保存，整理后的每道题回链对应原始提交。失败、取消、空答案或中断会明确标记，不当作正确完整答案。
- 整理稿不嵌入图片；每道题后立即显示参考答案、知识点、解析要点、来源和核对说明。图片只保留在 `原始记录.md` 和 `assets/`。模型提炼内容均待人工核对，不是官方标准答案。
- 模型整理会分别显示已完成、失败和待处理数量。全部失败时不会生成空整理稿；用户可显式只重试失败记录，且成功项不会再次调用模型。部分失败只有在明确选择后才导出已有整理结果，未结构化提交仍会链接回完整原稿；任何时候都可改为仅导出原稿。
- 重启后会恢复当前 `active`/`paused` 分段及可恢复的模型上下文。Change 018 后的新记录只持久化最近最多 10 轮非 system 的 Session/Record 引用，不保存 API Key、完整配置、Prompt、简历正文或 thinking；下一次请求始终使用当前模型、场景、Prompt 和简历配置。旧数据只能从自身已完成记录重建，界面会明确显示“按题库记录重建上下文，可能与当时实际上下文不同”。
- 解题 goroutine 尚未退出、有待发送截图、未落盘内容、整理或导出进行中时，历史续接会被拒绝。切换采用会话代际隔离，旧分段迟到的桌面流事件不会写入新分段；Mobile 清屏代际保持独立。
- 写盘失败时不要直接退出；恢复目录可写后点击“重试保存”。最终答案与对话快照会一起重试，成功后同步恢复模型上下文；强制终止进程仍可能丢失未落盘数据。
- 旧版 `会话记录` 和 v1 清单仅兼容读取，不自动移动、删除或覆盖。
- 输出文件是本地明文资料，可能包含私人截图，应自行管理访问和备份。只有在导出确认窗口中启用模型整理并提交后，相关截图和答案才会再次发送给已配置服务商。
- 题库偏好单独保存在系统用户配置目录的 `Q-Solver/questionbank-settings.json`，只承担默认目录、默认整理开关和兼容迁移信息，不与含 API Key 的主配置文件耦合。

**角色/场景：** 现有设置支持手动选择并保存，新场景用于后续请求；已发出的请求不会自动重答。`KeepContext` 开启时旧问答仍可能影响后续题目。本次未实现自动场景切换；“通用解题”识别题意不等同于程序自动切换 `domainId`。详见 [可行性分析](_dev/audits/010-question-bank-and-scenes.md)。

其他同类工具以后分别放在“求职笔试”下，与 Q-Solver 同级；不要混入 Q-Solver 的仓库。Q-Solver 已完成复制、校验和旧副本清理，分类输出目录现位于仓库外。

## 配置方式

第一次使用建议按这个顺序：

1. 打开右上角设置，进入 `模型与 API`
2. 选择 `OpenAI 兼容 Chat Completions` 或 `自定义请求模板`
3. 填写请求地址、API Key 和模型名称；本地无鉴权服务可留空 Key。兼容模式接受 API root 或完整 `/chat/completions` 地址，模板模式要求完整推理 URL
4. 兼容模式点击“刷新候选模型”只读取目录；模板模式不请求目录，需手填模型。“测试 API 连接”会发送一次文字请求，可能产生费用
5. 在“已配置连接”中选择已有记录，或点击“新建连接”；选择只加载草稿，不联网、不测试，也不会立即切换当前解题连接
6. 点击“保存 API 设置”保存并激活当前连接记录；“保存全部设置”同时保存其他页面草稿。活动记录不能直接删除，需先保存激活另一条记录
7. 到独立“场景”页选择角色，再到“截图”等页配置；场景变更通过“保存全部设置”生效

`CCR 本地网关` 位于兼容模式的高级快捷预设中，只填充草稿，不会自动联网、测试或保存。

**自定义模板：** 高级区可编辑请求 JSON、响应 JSON Pointer（默认 `/choices/0/message/content`）、鉴权 Header/前缀、额外 Headers。默认请求模板兼容 OpenAI 非流式 JSON；非标准接口仍需按其文档调整模板，并非任意服务都只填地址即可使用。

占位符必须独立作为 JSON 值，例如 `{"model":"{{model}}","messages":"{{openai_messages}}"}`。可用占位符包含模型、系统文本、最新用户文本、三协议消息数组、图片 data URL/Base64 数组；完整消息数组保留当前调用上下文。模板不执行脚本、循环或代码，不支持通用 SSE、协议自动探测或 fallback。模板模式收到完整 JSON 后一次性显示答案。模板不能承载图片时会在发送前拒绝截图请求。

**旧配置：** Responses/Anthropic 在打开设置时只转换为内存中的模板草稿，取消不写盘，保存后改为非流式 JSON；未保存时仍使用旧 adapter。迁移默认路径分别为 `/output/0/content/0/text` 与 `/content/0/text`，只提取该位置的单个文本块；若接口先返回 reasoning/tool block 或有多文本块，需要人工核对模板和响应路径，不代表完整等价于旧 SDK 的聚合/终态解析。

**安全限制：** 请求地址仅允许 HTTP/HTTPS，禁止内嵌凭据、query 和 fragment。模板最多 64 KiB、64 层嵌套，响应最多 4 MiB。额外 Headers 必须为字符串到字符串的 JSON 对象，拒绝重复名称、控制字符及 `Host`、`Content-Length` 等传输控制头。Key 只放在鉴权 Header，不注入模板或 URL。保存结果和错误不回显模板、Key 或 Header 值。目录失败保留手填模型，测试不自动保存。

无 Key 支持覆盖模型测试与截图解题；题库的模型整理入口仍保留既有 Key 前置要求，不属于本次修改范围。

成功保存后，完整连接记录会写入现有加密主配置，包括请求地址、API Key、协议、Endpoint、额外 Headers、响应格式、请求模板、响应 Pointer、鉴权 Header/前缀和模型。最多保存 20 条；记录默认按主机名和协议自动命名，也可手动修改。API Key 输入保持密码框，不提供明文显示按钮。选择记录只恢复草稿，只有“保存 API 设置”或“保存全部设置”成功后才会激活该记录。

配置加载失败时会显示“重新读取配置”，保存暂时禁用，以免默认空值覆盖原配置。场景列表失败不影响 API 配置读取；未改动的题库偏好不参与保存，题库保存失败也会与普通设置结果分别提示。

## 快捷键

默认快捷键如下：

| 动作 | Windows | macOS |
|:---|:---:|:---:|
| 截图 | `F8` | `Cmd + 1` |
| 发送解题 | `Ctrl + J` | `Cmd + J` |
| 快速解题 | `Ctrl + Shift + J` | `Cmd + Shift + J` |
| 中断解题 | `Ctrl + Shift + X` | `Cmd + Shift + X` |
| 隐身模式（防录屏） | `F9` | `Cmd + 2` |
| 隐藏 / 显示窗口 | `Ctrl + Shift + H` | `Cmd + 4` |
| 鼠标穿透 | `F10` | `Cmd + 3` |
| 微调窗口位置 | `Alt + 方向键` | `Cmd + Option + 方向键` |
| 滚动内容 | `Alt + PgUp / PgDn` | `Cmd + Option + Shift + 方向键` |
| 清空同步端显示 | `Shift + C` | — |
| 开始下一套笔试 | `Ctrl + Shift + N` | — |

> macOS 当前使用固定快捷键；Windows 支持在设置中录制和调整。
> 手机同步端会显示当前实际生效的快捷键；“滚动内容”按已保存的 `desktop`、`mobile`、`dual` 输出模式路由。手机服务不可用时，滚动控制安全回退到桌面。
> “清空同步端显示”仅支持 Windows，默认严格匹配左 `Shift + C`，可在“设置 → 常规”重新录制。快捷键只打开确认窗口，确认后才清屏；全局 Hook 命中后会吞掉该按键组合。升级时若检测到旧的隐藏窗口等动作仍占用该默认组合，会把旧动作置为未绑定并将组合迁给清屏，避免 `Shift+C` 隐藏主界面。
> “开始下一套笔试”仅支持 Windows 默认快捷键，可在“设置 → 常规”重新录制。它与主界面按钮共用确认流程，不会直接删除题库或清空同步端；默认组合若已被用户其他动作占用，升级时不会抢占。

### 重试、中断与快速解题

- 网络、超时、服务暂时不可用或流式响应中断后，错误卡片会在后端仍保留本轮快照时显示“重试本题”。重试复用原来的 1～3 张截图和同一题库记录，不要求重新截图；每次重试都会重新调用当前已保存的模型连接，可能产生新的模型费用。
- “中断解题”会取消当前 Provider 请求，但不是暂停或 token 断点续传。已经流出的正文会保留，并明确标为“内容可能不完整”；旧请求完全退出前，新的发送、快速发送和重试会短暂被拒绝。
- “快速解题”只在本次请求使用现有 `gen-speed` 场景，不修改设置中的持久默认场景。它用于要求模型尽快直接给出答案，但不保证网络、Provider 或服务端的固定响应时延。
- 新增快捷键可在 Windows 设置中重新录制。升级时仅在默认组合空闲时补入；若组合已被其他动作占用，新动作保持未绑定，不会抢占用户配置。

### 手机连接与滚动控制

- 在“设置 → 输出”查看手机连接入口。每次打开设置或进入该标签都会刷新服务状态；读取失败、服务未启动、端口不可用和服务就绪会分别提示，可重试状态可直接在页面恢复。
- 固定同步链接默认启用。首次升级到本功能时链接会变化一次；之后只要应用配置目录、局域网 IP 和端口不变，完整退出并重启仍可复用。固定的是 Token 与端口格式，不是网卡地址；DHCP、VPN 或网络切换仍可能改变完整 URL。
- “重试服务”只恢复监听，不换链接、不清屏；“重置同步链接”会立即让旧链接和旧 SSE 连接失效，并让新链接从空白状态开始；“清空同步端显示”只清同步页面的答案、分析、错误和页面内历史，不换链接。
- 清屏和重置不会删除桌面答案、题库记录、历史分段、截图、导出文件、普通配置或模型上下文，也不会取消正在解题的任务。清屏前任务的迟到 Mobile 输出会被显示边界拒绝，清屏后的新题可正常显示。
- 同步页面使用 HTTP Token 链接；任何能访问该地址并持有完整链接的人都可能查看同步内容。复制、截图或离线保存的旧内容无法被远程撤回。
- 清屏成功提示表示服务端状态已提交并广播；SSE 没有客户端确认机制，因此不代表每个终端已经肉眼显示为空白。
- 输出模式卡片中的临时选择只有点击“保存”后才生效；页面会同时显示当前实际生效模式，避免把未保存的 `mobile` 选择误认为已经改变路由。
- 同步端会显示普通/快速模式和中断终态，并在错误时提示回到桌面端重试；它保持只读，不提供远程重试或中断入口。
- 顶部上下箭头用于滚动答案。可点击箭头、使用已保存的全局快捷键，或把鼠标放在两个箭头组成的控制组上滚动滑轮。滑轮不会接管设置窗口、普通答案阅读区或系统其他区域。
- 手机正在查看历史答案时，桌面滚动命令只滚动当前手机页面，不会把历史选择切回最新答案；断线重连也不会重放旧滚动命令。

## 仅复制可填写答案与题号规则

- 需要核对题目对应关系时使用“复制题号＋答案”，例如 `16. C`、`20. AB`；使用汇总中的实际题号，不重新编号。桌面和同步端均支持，原有纯答案复制及桌面全文复制保留。

- 每轮解题（包含 1～3 张截图）要求在全文末尾输出“最终答案汇总”，单题也适用。桌面保留“复制全文”，新增“复制答案”；同步端参考答案卡也提供“复制答案”。
- “复制答案”只取本轮汇总中的可填写值：单选如 `B`、多选如 `AC`；多空题以 `；` 分隔在一行；多题按显示顺序逐行复制，不带题号、题干、解析或“答案：”前缀。
- 含“待核对”、重复题号、缺失或格式不合规时，复制答案不可用，不会改成复制全文。旧记录只有符合固定三列表格时才可临时恢复复制，原文件不变。
- 同一题库分段保存题号参考；关闭“保持上下文”、重启或真正续接后仍可使用。该参考只含受限题号，不含旧答案或历史聊天；截图的显式题号/章节号优先，不能确定时标“待核对”。它是辅助提示，不是 OCR 正确性保证。
- “开始下一套”后，新分段不继承上一套题号。完整原答案、截图与旧导出继续保留，不为提取答案增加第二次模型请求。
- 同步端“答题端快捷键”显示已保存的实际绑定，包含清空同步端、开始下一套；未绑定动作不显示。按键在答题电脑使用，不是在浏览器执行。
- 浏览旧轮时复制的是所选轮。浏览器权限或 HTTP 环境不允许复制且兼容路径失败时，会提示失败，请手动选择文本；不显示虚假的成功提示。
