# 变更请求 00

## 基本信息

- **Change**：013
- **名称**：question-bank-export-dialog（题库导出弹窗与试卷格式）
- **日期**：2026-10-20
- **状态**：已确认 / 待实现
- **来源**：用户对 Change 012 实际界面的复核反馈

## 用户请求

1. 消除主设置、顶部题库入口、题库面板和答案旁导出按钮之间的职责混淆。
2. 答案旁“导出题库”改为先打开确认窗口，可编辑单位、题型、题库名称和本次保存位置；目录默认取设置中的题库路径。
3. 默认名称结合单位和题型；单位不明确时使用可读编号，仍允许用户手动修改。
4. `原始记录.md` 继续保留全部截图和原答案；整理后的题库 Markdown 不再插入图片，改成“完整试题 + 文末参考答案与解析”的试卷格式。
5. 顶部状态明确表达“提交次数”而非题目数；已导出段不再显示为仍可写的“当前段”。
6. 让手动分段入口可见并解释自动分段：结束当前段后下一次解题自动创建新段；导出后同样自动封段。

## 已批准设计

- 设置页只负责长期默认目录和默认模型整理开关；单位、题型与题库名称属于单次导出字段。
- ActionBar 是当前段的主要导出入口，点击后打开导出弹窗；不在打开弹窗时调用模型。
- 题库面板聚焦当前段状态、结束本段、软清空、历史与重导出，移除重复的当前段主导出按钮和目录详情。
- ActionBar 增加“结束本段”快捷入口，仅在可写分段存在时启用。
- 有既有整理结果时可本地推断主要题型；否则使用当前分段类型或“综合笔试”。模型整理只有在用户明确确认后运行。
- 单位为空时使用 `笔试_YYYYMMDD_NN` 形式的本地编号；用户手动编辑名称时不再自动覆盖。
- 组织稿使用用户确认后的题库名称作为 Markdown 文件名；`原始记录.md` 与 `assets/` 保持固定名称和完整内容。

## 非目标与安全边界

- 不改变正常解题、KeepContext、Mobile 输出和快捷键协议。
- 不自动调用用户真实模型，不在弹窗打开时上传截图或消费 API 额度。
- 不删除、覆盖或重命名既有题库输出；重复导出仍生成新版本。
- 不修改 API Key、Token、BaseURL、简历、Config 或 agentmemory 配置。
- 不新增依赖，不升级 Wails/Go/Node 模块。
- 本 Change 不授权暂存、commit、push、Tag 或 Release。

## 验收标准

- 点击答案旁导出按钮先显示弹窗，能修改名称、单位、题型、本次目录和本次模型整理选择。
- 弹窗默认目录来自题库设置；取消不改变状态、不创建文件、不调用模型。
- 单位明确时建议名称包含单位和题型；单位为空时生成稳定、可读且避免冲突的编号名称。
- `题库.md` 或用户命名的组织稿不含图片语法，采用试题与答案解析分区；`原始记录.md` 仍包含全部图片引用和原答案。
- 关闭模型整理时明确仅导出原始记录，不生成误导性的空试卷。
- 顶部状态区分待记录、记录中、整理中、上段已导出、上段已结束和上段已清空。
- “结束本段”入口在 ActionBar 和题库面板语义一致；终态不显示不可理解的灰色“新建分段”。
- 相关 Go 测试、全量测试、vet、Go build、前端构建、Wails 构建与 diff 检查如实记录。
