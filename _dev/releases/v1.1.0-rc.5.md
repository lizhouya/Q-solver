# Q-Solver v1.1.0-rc.5

这是 `lizhouya/Q-solver` 个人 fork 的预发布版本，不是上游官方发行版，也不是稳定版。项目继续遵循 CC BY-NC 4.0，仅限非商业个人学习与研究。

## RC5 修正

- 修复 app 测试在 macOS/Linux 上只设置 Windows `APPDATA` 的配置隔离缺陷。
- 新增跨平台测试 helper，将 `APPDATA`、`LOCALAPPDATA`、`XDG_CONFIG_HOME`、`HOME` 和 `USERPROFILE` 统一指向每个测试独立的临时目录。
- 解题、原图重试、Mobile、题库和 Settings 测试不再读写 CI runner 或开发者的真实 Q-Solver 配置。
- `v1.1.0-rc.4` Tag 已创建，但其 run `43212159818` 中 macOS arm64 回归失败、Intel 取消、Create Release 跳过，因此没有 rc.4 Release；rc.5 采用前进修复，不移动或覆写 rc.4 Tag。

## 自 rc.3 以来的主要更新

### 解题工作流

- 截图恢复为最多三张，修复偶发快捷键阻塞，并在桌面和同步端显示真实截图数量与操作提示。
- 新增原图重试：视觉或网络请求失败时可复用本轮截图和上下文，不必重新截图。
- 新增中断当前解题，以及独立的快速解题模式；默认解题与快速解题共用同一安全任务管线。
- 修复 F10 快速解题、F12 删除截图及历史快捷键字段错配；桌面和同步端按 F8～F12 工作流顺序显示截图、发送、快速解题、中断和删除。
- 选择题改为先识别“原始选项字母 → 完整文本”映射，再判断正确文本并回填字母；正文、解析结论和最终汇总冲突时输出“待核对”。

### 模型与连接

- 增强 OpenAI-compatible、Anthropic-compatible、Responses 与 CCR 网关的协议识别、连接诊断和安全错误提示。
- 统一 API 连接 Profile，保存请求地址与密钥输入，支持刷新模型和测试连接。
- 视觉失败显示可操作错误，不再把空白或不可见图片响应误当作正常答案。
- 模型下拉列表展开时锁定设置页外层滚动。

### 题库、同步端与构建

- 改进题库整理失败恢复、逐题解析、历史分段保护和当前分段物理清空。
- 同步端优化答案空间、自动跟随、手动滚动、本地清理同步、截图状态及五项快捷键提示。
- Mobile 继续作为只读输出端，没有新增远程控制端点。
- 建立 `build/bin/**` 盘点、候选验证、哈希晋升、归档和回滚规则。
- 发布工具链固定 Wails v2.11.0，目标附件为 Windows amd64、macOS arm64、macOS amd64 和 `SHA256SUMS`。

## 下载与升级

- Windows x64：`q-solver-windows-amd64.exe`。首次运行可能出现未签名程序提示，请只从本仓库 Release 下载并核对 `SHA256SUMS`。
- Apple Silicon：`q-solver-macos-arm64.zip`；Intel Mac：`q-solver-macos-amd64.zip`。macOS 附件由 CI 构建，未签名、未公证，也没有人工桌面验收。
- 升级前备份自己的配置和题库输出，正常退出旧程序（包括托盘实例）。程序使用单实例锁，不要只隐藏旧窗口。
- 新版本继续读取原用户配置；不要把 API Key、Token 或 Mobile 连接 URL 复制到源码、公开文档或发布目录。
- 默认提示为 F8 截图、F9 发送、F10 快速解题、F11 中断、F12 删除；重绑定后同步端显示实际键名。

## 已验证与已知限制

- rc.5 Tag 前本地 Windows 已通过配置隔离合同、两个 rc.4 失败测试、app 全包、全仓 Go 测试、`go vet`、`go build`、`go mod verify`、19 个前端 Node 回归、Mobile DOM 回归和 Vite build。
- 本 Tag 的实际三平台构建与回归结果以对应 GitHub Actions run 为准；自动构建不能代替人工验收。
- Windows race 测试进程启动仍返回 `exit status 0xc0000139`，状态为 `BLOCKED`；不宣称 race 通过。
- macOS 附件未经人工 GUI 验证，部分较早 Change 的真实 Provider、题库导出/整理矩阵仍保留 `NEEDS_USER`；因此本次只发布 RC，不标记稳定版或 Latest。
- 连接测试、真实解题和显式启用的题库模型整理可能调用服务商并产生费用。
- 提示词约束只能降低选择题字母与文本错配概率，不能保证模型绝对正确。答案与整理稿均为参考内容，重要结论请自行核对。
- Vite 主 chunk 仍有大于 500 kB 的既有警告；本次未拆包或新增依赖。
