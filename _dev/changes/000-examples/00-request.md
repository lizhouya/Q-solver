## 1. 背景与问题

当前热键 `Ctrl+Shift+S` 与某录屏软件冲突，导致在录屏场景下快捷键无法触发截图。

## 2. 目标

让快捷键组合可被用户自定义，并默认避开常用录屏软件的全局热键。

## 3. 验收标准

- [x] 设置页新增快捷键配置项，可修改「开始截图」组合键
- [x] 修改后立即生效，无需重启应用
- [x] 与录屏软件常用热键不冲突

## 4. 非目标 / 明确不做

- 不改动官方默认快捷键 UI 布局
- 不引入第三方热键库（保持零新增重依赖）

## 5. 影响面预估

- 涉及业务源码文件：`pkg/shortcut/`、`frontend/src/` 下的设置页
- 需要同步更新的文档：`_dev/changes/001-example-feature/` 全系列
- 潜在风险：热键注册失败时的降级策略

## 6. 附带约束

- 遵循项目现有 Go 与前端代码风格
- 不提交任何 secret
- 在 `dev/qsolver-custom` 分支开发，不触碰 `main`
