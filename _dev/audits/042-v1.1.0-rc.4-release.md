## 自动 Release 合同

当前 workflow：

1. 监听所有 `v*` Tag push。
2. 三个平台固定 Wails v2.11.0 构建并运行全量 Go、vet、设置回归和 Mobile DOM 回归。
3. Create Release 从 `_dev/releases/${tag}.md` 读取正文。
4. `contains(tag, '-')` 使 rc.4 自动成为 prerelease。
5. `make_latest=false` 保证不会标记 Latest。
6. 上传三个平台附件与 `SHA256SUMS`。

因此 Tag push 后不允许再手工执行 `gh release create`；只能监控并核对自动发布结果。
