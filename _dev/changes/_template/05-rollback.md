## 回滚策略

- [ ] **A. 全量还原**：将涉及的业务源码文件恢复为 `main` 基线版本（或变更前 commit）。
- [ ] **B. 定向还原**：仅还原特定文件/配置，保留部分变更。
- [ ] **C. 配置级回滚**：仅回退 `config.json` / `.env` / `wails.json` 等配置项改动，代码可保留。
- [ ] **D. Git 级回滚**：`git revert <commit>` / `git reset --hard`（注意二次开发分支与官方 `main` 的关系）。
