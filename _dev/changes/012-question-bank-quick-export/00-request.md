## 1. 背景与问题

Change 010 的“开始场次 → 逐题记录 → 结束并导出 → 可选模型整理”已经通过基础实测，但真实使用暴露出以下问题：

1. 用户已选择 `求职笔试/题库` 时，导出器仍重复追加同名目录，路径过长且混乱。
2. 题库路径只能在独立题库面板配置，没有进入主设置界面。
3. 显式开始和结束场次不符合连续做题习惯；答案旁“导出”仍是答案图片导出。
4. 缺少清晰的记录分段和清空语义，容易重复导出上一批题目。
5. 手机端没有实际快捷键提示；现有滚动快捷键只控制桌面内容。
6. `go vet ./...` 在 Windows hook callback 处报告两处 `unsafe.Pointer` 告警。

## 2. 目标

- 配置题库路径后自动记录，改用“当前分段”管理，不再要求日常手动开始场次。
- 答案区“导出”一键整理并导出当前段；成功后自动封段，下一题进入新段。
- 提供手动新建分段和安全清空当前段，使后续导出不包含旧段。
- 在主设置增加并列“题库”标签，配置最终目录、单位名称和模型整理授权。
- 精简导出结构，配置路径直接作为最终题库目录。
- 手机端显示实际快捷键，并允许电脑按钮或既有滚动快捷键按 outputMode 控制桌面/手机答案。
- 消除两处 Windows hook `go vet` 告警，不通过忽略规则绕过。

## 3. 验收标准

- [ ] 配置目录后的首次解题自动建立当前段并保存全部截图与答案。
- [ ] “导出题库”处理当前段全部记录，提炼题目大类、题型、题干、知识点和解题要点。
- [ ] 成功导出后当前段封存；手动分段后导出不包含上一段。
- [ ] 清空当前段需要确认，旧记录不进入后续导出，首版不立即物理删除原始文件。
- [ ] 主设置可配置最终题库目录、单位名称和一键模型整理授权。
- [ ] 配置 `E:/DATA/求职_AI/输出/求职笔试/题库` 时，最终目录直接创建在其下，不重复生成 `求职笔试/题库`。
- [ ] 导出目录命名为 `YYYY-MM-DD_HHMMSS_<单位或笔试题库>`，冲突追加顺序号；内部固定为 `题库.md`、`原始记录.md`、`assets/`。
- [ ] 旧版路径偏好和历史会话保持可读，不删除或覆盖已有输出。
- [ ] 手机页显示实际快捷键；desktop/mobile/dual 的滚动目标正确，SSE 重连不重放旧命令。
- [ ] 原答案图片导出仍可从历史项入口使用。
- [ ] `go vet ./...` 不再报告两处 Windows hook `unsafe.Pointer` 告警。
- [ ] 聚焦测试、全量 Go 测试/构建、前端构建和 Wails 构建结果均如实记录。

## 7. 2026-10-20 Mobile 人工反馈回修

用户在设置“输出”页选择 Mobile 后发现手机连接入口消失，并要求明确顶部上下箭头用途，同时支持通过键盘与鼠标滚轮控制手机端页面上下滚动。

本次回修验收标准：

- [ ] 每次打开设置或进入“输出”标签均刷新 Mobile 状态，并区分状态读取失败、服务未启动、初始化失败、端口不可监听和已就绪。
- [ ] 临时选择的 `outputMode` 明确标注为尚未保存；连接服务状态与模式草稿独立展示。
- [ ] Mobile 服务启动失败后可从设置页安全重试；重试不得重复创建 Bridge、重复订阅配置或突然隐藏当前桌面窗口。
- [ ] 顶部上下箭头继续复用现有滚动路由；全局键盘快捷键保持有效。
- [ ] 鼠标滚轮只在顶部箭头控制组内生效，不抢占设置弹窗、答案阅读区和窗口其他区域的普通滚动。
- [ ] 手机端控制帧只执行一次滚动，不重建答案/历史 DOM、不重置历史答案选择；SSE 重连不重放旧命令。
- [ ] 不修改 Windows 全局鼠标 Hook，不新增协议或依赖，不输出 Mobile URL/token。

该反馈属于 Change 012 原有 Mobile 提示、滚动路由与真机验收范围，不新建 Change 014。
