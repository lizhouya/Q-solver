## 功能摘要

- 单题、多题统一要求末尾三列汇总，Go 统一解析并与完整回答原子保存。
- 桌面区分“复制全文”与“复制答案”；同步端参考答案卡也提供“复制答案”。选择题复制选项，其他题型复制填写值，多题按显示顺序逐行输出。
- 待核对、重复题号或结构不合规时禁止整轮答案复制，不回退全文、不遗漏某行后悄悄复制剩余部分。
- 编号摘要来自当前 Session 的已完成 Records，不依赖 KeepContext 或最近 10 轮聊天；显式截图编号优先，新 Session 不继承上一套编号。
- Mobile 提示显示实际保存的快捷键，补齐清空同步端与开始下一套，明确是在答题电脑按键。

## 关键实现决策

- 没有第二次模型调用，没有从全文扫描选项字母，没有新增 Mobile store/HTTP API/确认协议。
- 原 Answer 不被纯答案覆盖；复制文本由 Go 从结构化值计算，Desktop/Mobile 不各自维护解析器。
- 关闭 KeepContext 要清 Solver、refs 和持久化快照；明确空快照不能用 nil 替代，否则兼容重建会复活历史。
- Mobile 浏览旧轮时保持选择，后台新帧不会替换旧轮的复制内容；要重新跟随最新可点击最新历史条目。
- 依赖、runtime、正式 EXE 和旧验证程序使用构建前哈希保护；bindings 另保留本次生成前副本供差异审计。

## 适用边界与遗留验收

- 模型返回内容仍是参考答案，不是经过事实核验的标准答案。
- 严格解析只证明输出结构合规，不能验证 OCR 是否正确、题号是否与截图真实对应或答案是否正确。编号参考可减少漂移，但不能保证复杂跨图同题识别；有疑问必须核对截图。
- 复制契约每题一行、多空用中文分号；多行代码、复杂公式等若未以约定纯值输出，按钮可能不可用，全文始终保留可手动复制。
- 旧自由格式记录不批量转换；仅符合新表格契约的旧答案支持只读临时解析。
- HTTP/浏览器权限可能阻止 Clipboard API；兼容复制失败时明确提示，不虚报成功。
- Windows GUI 和真实模型遵循效果尚未由用户验收；race 仍为环境启动错误 `0xc0000139`，不能用普通测试代替。
