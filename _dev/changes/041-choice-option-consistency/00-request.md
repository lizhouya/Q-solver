## 1. 背景与问题

用户发现选择题回答中知识结论正确，但模型给出的选项字母和最终答案汇总错误。示例题中 Java 8 使用 Metaspace（元空间）替代 PermGen，原题 A 为元空间，但模型正文写“选 C”并在汇总中继续填 C。

只读审计确认：前端和 `pkg/answersummary` 没有把 A 改成 C；模型响应本身已经包含错误字母。解析器只能验证单选答案是一个合法字母，无法从截图重新建立字母与选项文本映射。

## 2. 目标

1. 强制模型先识别当前截图中的“原始选项字母 → 选项文本”映射，再判断正确文本，最后回填原字母。
2. 最终输出前复核选项字母、选项文本、解析结论和最终答案汇总指向同一选项。
3. 映射不可辨认或存在冲突时输出“待核对”，不得猜测字母。
4. 快速解题保持简洁，但不能跳过内部映射和一致性检查。

- [x] 提示要求选择题正文结论包含原始字母及对应选项文本，并与最终汇总一致。
