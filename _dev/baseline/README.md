# _dev/baseline/ — 开发基线情报

本目录存放 Q-Solver 二次开发的**开发起点快照**：环境搭建记录、依赖基线、构建链路、API 版本等"一次性完成、长期参考"的资料。

## 内容说明

### [Q-Solver 开发环境准备报告.md](./Q-Solver%20开发环境准备报告.md)

- **来源**：仓库根目录（由本次治理初始化迁移而来）。
- **内容**：Q-Solver 二次开发的前置环境准备结论（工具链、依赖、构建与运行链路、GUI 技术栈验证、启动方式等）。
- **定位**：开发起点的**环境基线**——后续任何环境变更应与此文档对照，产生差异时记录到 `_dev/changes/` 的相关变更中。

## 更新规范

- 本目录只接收**一次性基线资料**，不接收增量开发记录。
- 增量记录一律进 `../changes/`（变更档案）。
- 若环境发生重大升级（如 Go 版本、Wails 大版本、Node 主版本），建议：增补本目录一份"环境变更记录"，并将对应变更归档于 `_dev/changes/`。
