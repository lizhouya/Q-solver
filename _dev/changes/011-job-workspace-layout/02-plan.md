3. 不擅自关闭用户进程；若 VS Code/Wails/运行程序的占用使迁移不能安全完成，停在迁移步骤，说明需关闭/重新打开的内容，不强行删除或终止。

6. 每项迁移记录结果；中途失败停止并按清单恢复，不自动覆盖任何已存在目标。
7. 新目录 Git 预检和校验：HEAD、分支、remote 不变；仓库内相对路径不变，不应出现全量源码删除/新增；原有未提交内容与本次改动均在。
