## 2. 关键代码现状

当前全局规则只要求：选择题明确给最终选项；汇总中单选填写一个大写字母。`gen-speed` 进一步要求只输出最终答案或 option key。两者都没有强制模型先识别截图里的字母与文本对应关系。

示例模型响应在进入应用前已自相矛盾：知识解释指向“元空间”，但结论和汇总均写 C。由于正文和汇总中的字母彼此一致，现有格式解析无法识别该语义错误。
