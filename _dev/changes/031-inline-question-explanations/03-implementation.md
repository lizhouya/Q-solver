## 实现细节

- 整理稿标题由 `## 试题` 改为 `## 试题与解析`。
- 保留分类、题型与全局题号层级；每个五级题目标题下增加六级“参考答案与解析”。
- `writeMarkdownList` 忽略空白列表项；列表无有效内容时输出 `- 待核对`。
- 参考答案和核对说明为空时也回退为“待核对”。
- 每题末尾增加 Markdown 分隔线，提高连续阅读时的视觉区分。
- 删除第二次集中遍历答案的渲染路径，避免题目与解析重复分区。

## 与计划的偏差

- Wails 独立构建成功，但自动启动时检测到用户已运行 `Q-Solver-change030-latest-validation.exe`；新实例受 `SingleInstanceLock` 影响以退出码 0 正常退出。为保护用户现场未停止旧实例，因此 Change 031 的 GUI 启动与真实导出标记 `NEEDS_USER`。
- 其余实现与计划一致。

## 关键决策

- 保持单一整理稿，不增加布局选择器或额外文件。
- 不使用 Markdown 表格左右栏。
- 不改模型、持久化或 Wails API。
- 不为自动验证停止用户现有 Q-Solver 进程。
